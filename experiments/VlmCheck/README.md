## 입력과 질문

| 입력 | 그림 |
|---|---|
| A | 화면 전체 + 후보 빨간 박스 |
| B | A + 후보 주변(박스의 3배, 한 변 최소 256px)을 긴 변 512px 로 키운 그림 |
| C | B + 2초 전·뒤 화면(같은 자리 박스) |
| D | 키운 그림만(확인 단계에서 더함) |

- 질문(`run_vlm.py` 의 `SYSTEM`): 관제 보조 역할, 보이는 것만·모르면 unknown, 화면에 겹친 글자는 근거로 쓰지 않음, 항목 뜻과 판정 정의. 사용자 글에 그림 구성과 검출기 라벨·신뢰도를 준다
- 답은 Ollama 구조화 출력(JSON 스키마): 물체 종류·멈춤·위치·차로 위 사람·출동 차량·라바콘·손상·연기/불·정체·**판정**(incident · normal · detection_error · cannot_judge)·한국어 설명
- `temperature 0` · `seed 7` · `num_ctx 8192`, 출력 한도 768 토큰(생각 모드 8192)

## 결과 2 — 확인: 설명을 먼저 쓰게(desc_first) + 키운 그림만(D)

1차의 Qwen 답은 설명과 판정이 서로 안 맞았다 — JSON 을 스키마 순서대로 쓰므로 **장면을 보기도 전에 물체 종류(none)부터 고르고** 거기에 맞춰 판정한 것으로 봤다.
설명(`description_ko`)을 맨 앞에 두고(`make_schema(desc_first=True)`), 화면 전체 없이 키운 그림만 주는 D 를 더했다(`--probe`, 빠른 두 모델).

| 설정 | 입력 | 판정 맞음 | 유고 8 | 정상 5 | 함정 3 | 가짜 2 | 한 번 시간 |
|---|---|---|---|---|---|---|---|
| qwen3.5-4b 설명 먼저 | B | 61% | 5 | **5** | 0 | 1 | 3.1초 |
| qwen3.5-4b 설명 먼저 | **D** | **83%** | **8** | **5** | 1 | 1 | **2.5초** |
| gemma3-4b 설명 먼저 | B / D | 44% / 50% | 3 / 3 | 5 / 5 | 0 | 0 / 1 | 3.7 / 2.8초 |

- **qwen3.5-4b + 설명 먼저 + 키운 그림만**: 유고 8 · 정상 5 를 모두 맞혔다. 설명도 장면과 맞는다 — P5 "도로 중앙에 정차한 흰색 승용차, 차량 뒤쪽에 사람", P8 "도로 왼쪽 갓길에 흰색 트럭이 정차",
  N1 "신호등 앞에 정차한 승용차, 주변도 정체", N3 "도로변 주차장에 정차한 차량". 흐림(T1)은 cannot_judge 로 맞혔다
- 같은 모델도 화면 전체를 같이 주면(B) 멈춘 승용차·갓길 트럭을 "정상 주행 중"이라 했다 — 작은 박스보다 장면 전체를 본다
- 남은 약점: **검출기 라벨을 믿는다**(T2 — 흐린 덤프트럭을 'bus' 라벨대로 "주행 중인 버스"), **글자 위 가짜 박스에도 장면을 보고 incident**(S2 — 키운 그림에 아래 사고 현장이 같이 담김),
  검은 화면은 detection_error(정답 초안은 cannot_judge — 앱에선 둘 다 '확인 안 됨'이라 실제 차이는 작다), 물체 세부(덤프트럭 → 견인차)
- gemma3 은 설명을 먼저 써도 유고를 normal 로 보는 쏠림이 그대로다

## 결과 4 — 3차: 추적기 사실을 주고 '왜 멈췄나'만 (`--round3`)

2차에서 그림으로는 멈춤을 못 가른다는 게 드러나서, 멈춤·차로는 추적기 사실로 글에 주고(`추적기: 박스 안 차량은 N초째 거의 움직이지 않았고 차로 구역 안에 있다(확인됨)`)
'왜 멈췄나'만 물었다(`SYSTEM3`). 판정 이름도 바꿨다(2차에서 detection_error 를 '아무 일 없음' 뜻으로 썼다): accident_or_breakdown · normal_stop · not_vehicle · unusable_image.
근거(`cause_evidence`)와 정상 맥락 항목(`queue_or_signal`·`parking_area`)도 받는다.

장면은 `cases.json` 의 `round3` 중 **멈춘 지 3초 이상인 20개**(규칙이 실제로 고를 후보) — 사고·고장 10(출동 차량 5: P1·P2·P4·P9·P11, 그 밖 5: 트렁크 열린 사고 승용차 둘·덤프트럭·갓길 트럭·'bus' 라벨 덤프트럭),
